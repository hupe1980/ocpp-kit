What happens without asking

  • The identity becomes the last path segment, as Part 4 §3.1 prescribes.
  • Anything sent before the CSMS accepts the station is queued — B02.FR.02 forbids sending it — and released the moment it does.
  • Reconnects follow the back-off of Part 4 §5.4 and keep the queue, so a reconnect does not repeat BootNotification.
  • Transaction messages are retried on the linear schedule §3.7.1 defines, in chronological order, and queued durably while offline.

Why another OCPP crate

Error codes are exact

OCPP has five distinct codes for five kinds of bad payload, and answering with the wrong one is a conformance failure. A missing member is an OccurrenceConstraintViolation; a string where an integer belongs is a TypeConstraintViolation; on 1.6 a format violation is spelled FormationViolation.

Numbers are exact

Every OCPP number is a decimal mantissa and scale, never an f64. A meter reporting 2935.600 kWh claims three decimals of resolution, and it goes back out as 2935.600; a session’s energy is the exact difference of two registers.

Typed messages →

The billable value

Under calibration law a customer may only be billed for the record the meter signed — which 1.6 hides inside a string and whose public-key field the specification and its own example message disagree about. Both shapes are read, and the record is carried verbatim.

Signed meter values →

The types cannot drift

Every action’s request and response is round-tripped through pseudo-random schema-valid payloads and validated back against the official schema — over 9 000 round trips per test run.

How it is verified →

Compression, because 2.1 requires it

Part 4 §3.4 makes RFC 7692 mandatory for a CSMS. No general-purpose Rust WebSocket crate implements it, so the frame layer is in this crate — checked against an independent implementation and fuzzed.

The WebSocket layer →

Real hardware, not just the spec

The strict default is what the schemas say. A lenient policy additionally accepts offset-less timestamps, numeric strings and undefined enum values — via a repair loop that only runs after a strict parse has failed.

Talking to real hardware →

Runs where the protocol runs

  • no_std + alloc for layers 0–4
  • Tokio
  • WebAssembly
  • thumbv7em-none-eabihf, checked in CI
  • #![forbid(unsafe_code)]
  • MIT or Apache-2.0

With default features there is no async runtime, no TLS and no domain logic in your binary — just the types, the framing and the engine.
